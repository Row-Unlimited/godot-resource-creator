# GENERAL PLUGIN MANUAL

This page describes basic functions of the plugin as well as its quirks to give you a general understanding of how to use it.  
This page also includes general tips that might make the usage of the plugin easier.

## Tips and Tricks

- When editing an Array you can change the position of any element by clicking the arrow keys that are to the side. If you however have currently focused this element in particular you can also move it by pressing alt + arrow_keys
